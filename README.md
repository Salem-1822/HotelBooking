# 📖 About

**HotelBooking** is a modern hotel booking and management system developed with **Laravel 12** and **Bootstrap 5**. It provides a complete platform for managing hotels, cities, rooms, reservations, customers, and reports through dedicated **Super Admin** and **Hotel Admin** dashboards.

# 🚀 Installation

```bash
git clone https://github.com/Salem-1822/HotelBooking.git

cd HotelBooking

composer install

cp .env.example .env

php artisan key:generate

php artisan migrate

php artisan serve
```
