## 📌 About HOTELIA

HOTELIA is a modern hotel management system created using Laravel.  
It helps administrators manage hotels, rooms, reservations, clients, and staff with an easy and secure dashboard.

---

## ✨ Main Features

✅ Admin Dashboard  
✅ Manage Hotels  
✅ Manage Rooms  
✅ Booking Management  
✅ Customer Management  
✅ Staff Management  
✅ Secure Authentication  
✅ Responsive Design  

---

## 🛠️ Technologies Used

- Laravel  
- PHP  
- MySQL  
- Blade Template  
- Bootstrap / CSS  
- JavaScript
